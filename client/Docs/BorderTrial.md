# 边境试炼：可通关的横版关卡

入口：**Tools → BigWorld → 正式关卡 → 打开边境试炼**。正式场景位于 `Assets/_Project/Game/Scenes/BorderTrial.unity`，已设置为 Windows 打包入口。原框架整合示例保留在 `_Project/Examples`。

## 操作与目标

- 营地选择猎人并装备至少一把武器，点击“开始行动”出战。方向键切换界面按钮，Enter激活当前选中按钮。
- A / D 或左右方向键：行走；按住 Shift 奔跑，有地面加减速与空中控制。开始奔跑要求体力＞1，跑动不扣体力，但暂停体力恢复。
- W / S 或上下方向键：瞄准上下方，与A/D组合可斜向瞄准；松开全部方向键停下并保持角度。青色准星显示当前枪械瞄准方向，站立时可向下射击，纯竖直输入不会移动或跳跃。移动端自动显示摇杆／动作按钮，编辑器可通过HUD的ForceTouchControls预览；按住调查后用摇杆移动视角。暂停、失焦、挂起或安全区变化会清除手势，回到游戏需重新按下。触控模式保存并停用键盘读取，退出后还原。实体设备与移动包尚未验收。
- C：地面切换匍匐／站立。匍匐时走速、碰撞高度和枪口高度减半，不能奔跑；瞄准限制在当前角色面朝的前方水平至正上方，可左右转身。起身前检测站立空间，受阻时显示提示并保持匍匐；空格只有在成功起身后才跳跃。道具准备减速与匍匐相乘；准备、攻击、换弹、暂停、受伤和调查视角期间不能切换姿态。
- E／交互按钮：打开位于`(28.5,2.55)`的即时弹药柜，或位于`(41.5,2.55)`的3秒封锁弹药柜，再次交互领取其中弹药。触控附近奔跑按钮变为“交互”，计时中变为“取消”。延时开柜要求静止；移动、瞄准、调查或其他动作取消进度，重试完整等待。暂停冻结，受伤、死亡、失焦、输入模式／安全区改变和离开范围取消。距离1.6内且无遮挡、地形已加载才可开始；跨区保留已开柜和已用补给，新局刷新。
- 高台梯子：站立靠近`(43.25,2.05)`或上端`(43.25,4.05)`按E上梯，触控附近奔跑键切为交互。W/S／摇杆上下攀爬，左右主方向尝试安全离梯；上端出口在`(44.45,4.05)`，受阻时停在梯子上，可向下返回。梯上只接受方向操作，攻击、道具、跳跃、匍匐、调查及重复交互无效；暂停仍可用。失焦和应用挂起清除方向、保留依附，伤害／死亡／停用恢复原重力。梯子复用现有贴图绘制，未制作专用攀爬动画。
- Space：跳跃；松开可短跳，支持离地后 0.12 秒容错与落地前 0.12 秒输入缓冲。
- J：射击，可长按连续开火；每次成功开枪固定当时的二维方向，转向不会改变已经接受或已出手的那一枪。K：近战（成功启动消耗25体力），继续沿角色面朝，不跟随枪械上下瞄准。攻击继续使用 SkillEditorKit 和 `SkillActor2D`；暂停、调查视角、受伤、死亡和关闭操控时拒绝瞄准输入，换弹时可调整下一枪的方向，但不能射击。
- R：换弹；1／2：切换携带的第1／2把武器（仅带手枪时1就是手枪）。两枪独立弹匣、共享备弹；暂停冻结换弹，切枪或受伤打断换弹。每次出战补满72发基础弹药，包含所有已装填子弹。
- 步枪可穿过x30.5／32.5的两处木掩体，每件保留75%弹丸伤害，穿两件后为14.0625；手枪会被挡住。两处木板可正常奔跑跳过，普通实体墙不可穿。弹药支持独立数量、每颗伤害、散射、距离和穿透配置，多弹丸共耗一发子弹、各自命中减伤；正式两枪仍为单弹丸。旧枪械没有DefaultRound时沿用原Damage数值及单颗12距离配置。
- Q：切换道具；F：使用选中道具。先在营地“道具整备”购买并装备，常规工具／消耗品各2栏。医疗和投掷准备期间减速50%，受伤打断且不扣次数，暂停冻结准备；匕首沿用近战攻击动作并消耗25体力。
- 飞刀／炸药使用当前二维瞄准。按F开始准备时固定该次方向与姿态高度，移动后从释放位置出手；准备中转向不会改写这一投。站立可向下投掷，匍匐时仅允许前方至上方并降低出手高度。HUD显示方向锁定提示，飞行拖尾随实际运动方向变化。
- 出生点右侧的黄色方块是弹药补给箱，靠近按E补充最多12发共享备弹。全满时不会消耗，成功补给后变灰，本局只能用一次；返回营地后重置。
- 蓝色箱子是道具补给：E随机给一个未满工具补1次；工具全满后才向空消耗品栏随机补给。橙色拾取物直接填入空消耗品栏。全满保留、领取后变灰，地图卸载重载不会重复发奖。
- 体力在奔跑／跳跃／近战中断恢复后等待2秒，以20/秒恢复。脱战6秒后生命以5/秒恢复至当前血段上限；默认100生命分为4段25。
- Esc：暂停 / 继续。暂停菜单可确认放弃行动并返回营地，代价为永久失去出战猎人与装备。胜利后按R返回营地，死亡后点击“返回营地”；正式模式没有检查点复活。
- 按住V并用方向键移动调查视角寻找蓝色线索，松开V后靠近按E调查。收集三条线索定位随机区域中的Boss；击杀后按E拾取赏金，会生成独立第二波守卫。可以携赏金撤离，也可以刷怪后不带赏金直接撤离：到最右侧出口，无敌人干扰时连续停留10秒，离开／争夺清零、暂停冻结。无赏金也保留猎人、枪械、技能、道具剩余次数和血段；资金为0，仅结算真实线索、击杀及现有撤离基础经验。Boss已死但未拾取时保留Boss经验，不自动获取赏金或触发第二波。守卫／Boss蓄力时会变色，可以走位躲避。
- Boss黄色预警弧线对应18伤害挥砍，瞄准线对应16伤害能量弹，均在前摇开始时固定方向。100／50生命阈值各触发3秒狂暴，圆环冲击25伤害，矩形预警冲刺22伤害；范围攻击检查遮挡，冲刺以真实碰撞停在墙和坑边。暂停冻结全部技能，复活抑制取消攻击但不延长狂暴。具体技能名称和数值是验证配置。
- x36附近的蓝色护甲精英受到的伤害减半，普攻有黄色前摇；x59附近的青色召唤者没有普攻，会召唤绿色单位。召唤物有独立生命，可先击杀；离开本体和召唤物的范围3秒后也会消失，6秒冷却后才可再召唤。拾取赏金后两类精英再各刷一只，保留第一波存活者并扩大警戒；精英和召唤物靠近出口都会阻挡撤离。
- 两面旗帜分别是断桥营地和边境前哨，在正式模式中只记录经过的地标。赏金撤离后写入账号资金，猎人和其装备保留；死亡后移除该猎人与装备，未携带的仓库装备和其他猎人保留。

营地操作、出战及结算自动保存到 `Application.persistentDataPath/Hunter/career-v1.json`。行动中退出（包括编辑器停止播放）视为放弃，下次进入时结算永久损失；不保存地图中途进度。主文件原子替换，`.bak`保留上次成功存档；主文件损坏时恢复备份并保留损坏文件，两个文件均损坏或版本过新时阻止进入，不会静默重置账号。写入失败时不发布该次数据变更；结算写入失败停留在错误页，修复磁盘问题后点“重试存档”。

初始资金500、1名装备步枪和手枪的招募猎人、仓库各1把备用枪。招募100、步枪150、手枪75，最多5名猎人。招募模板武器负重3、技能携带价值上限14；救济模板负重2、技能价值上限10，不能同时装备步枪和手枪。技能容量按当前持有技能价格合计，未花费技能点另计；移除、一次性技能使用和死亡技能消耗会释放容量。名单为空（包括最后一名猎人退役）可领取新救济猎人：优先取仓库手枪／步枪，否则有钱扣75买手枪，资金不足则赠送手枪。两者共享100生命及基础移动／体力配置；名称和数值属于验证配置，非草案最终数值。

猎人从1级开始，每100经验升一级、获得1技能点，最高10级／900累计经验；升级不直接改变基础生命和伤害。调查每条线索25经验、每名小怪20经验（含第二波）、Boss100经验、成功撤离100经验；局内显示预计经验，成功撤离后才统一保存。满级后仍能出战获得赏金，但不再积累经验或技能点。

营地点击“猎人技能”查看所选猎人的点数、效果和购买／移除按钮。格斗节能1点：近战体力消耗25→20；快速装填2点：所有携带枪械换弹时间×0.75；稳定瞄准3点：所有携带枪械射击间隔×0.8。各技能只能持有一份，营地购买后下次出战生效，不修改弹匣容量。主动移除1点技能返还1点，其他返还一半并向下取整（2点／3点均返还1点，4点返还2点），再次购买支付原价。操作即时保存，保存失败不扣点、不授予／移除技能。切换猎人重新计算加成，永久死亡或退役不转移已学技能。技能价格与倍率为验证配置。

“投球好手”为道具数值类常规技能，购买2点、移除返还1点：飞刀投掷距离8→12、炸药束6→9；匕首和医疗道具不受影响，伤害、准备时间、爆炸半径和次数保持原值。营地技能列表可滚轮／拖动，方向键选到隐藏技能行时自动滚入视野。局内拾取投球好手立即影响下一次准备的投掷，当前已投出的物体保持原射程，不重复叠乘；成功撤离与消耗死亡技能复活保留，永久损失时随猎人消失。投掷物HUD显示当前最远距离。

“死灵法师”是第4项技能，购买需4点，也可能在三个刷新点随机获得。当前猎人受到致死伤害或坠出地图时自动触发：先保存技能消耗，再恢复50%生命，普通地形原地复活，坠出地图回到最近记录的落脚点。每份技能仅触发一次，技能消耗后不返还点数；再次购买或拾取新的同名技能才可再触发。所有死亡类技能在这次复活后移除，三项常规被动保留；当前只有死灵法师属于死亡类。复活不回满体力、不补弹、不切枪，也不重置任务、Boss、第二波或线索；携带的赏金仍先掉落，之后可重新拾取。

复活后的3秒按游戏时间计算，暂停冻结，HUD显示剩余时间。三类怪物清除已锁定目标／攻击蓄力，期间不能因该猎人进入警戒；玩家仍可行动，效果不会挡住其他伤害，不属于无敌。技能消耗保存失败时角色保持死亡、游戏冻结，点击“重试存档”成功后才复活，其他入口不能跳过该事务。再次致死而未重新获得技能时正常永久死亡；放弃行动和中断存档载入始终执行永久损失，不触发复活。

局内在横坐标17、37、55附近有三个技能刷新点，默认每点75%概率生成一张随机青色技能卡。靠近1.6单位内、无遮挡、未攻击／换弹／受伤且未进入调查视角时按E拾取；暂停或死亡时无法拾取。技能当场生效，左侧HUD显示已学技能；生命、体力、弹匣、备弹、持枪选择和冷却进度不会被重置。已学技能保留在原地，不叠加、不转化点数；离开后返回同一区域也不会重置拾取状态，新行动才重新随机刷新。拾取写盘失败不获得技能、不消耗卡片，提示按E重试。

拾取技能不直接发放技能点，成功撤离后保留；回营地移除时与购买技能采用相同返还规则，因此合法返还可使当前点数超过该猎人升级获得的点数。死亡、放弃或中断行动仍永久丢失猎人及其全部技能，重新登录不会保留正在出战猎人的拾取收益。刷新位置、概率和技能数值均为验证配置；可在Level Session对象挂载`HunterSkillLoot2D`修改，未挂载的已有场景自动使用默认配置。

道具整备提供匕首（25资金／伤害30）、急救包（40／3次／每次恢复50生命／准备2秒）、飞刀（30／3次／伤害30／准备0.5秒）、生命针剂（35／恢复75生命／准备1秒）和炸药束（60／伤害60／半径2／准备0.8秒）。医疗与投掷不耗体力，医疗不能在满血时使用，可以跨血段治疗但不会超过最大生命。伤害、价格与数量为验证数值。

使用次数先保存再产生治疗或投掷效果；保存失败时效果不生效、次数保留，可按F重新准备。普通工具耗尽仍占栏位，消耗品用完移除。卸装、撤离、再次出战和死灵法师复活均保留剩余次数；初始账号和迁移账号不免费发放道具。飞刀／炸药束逐步检测飞行碰撞；炸药落到首次撞击点或最远位置后等待0.6秒爆炸，墙体遮挡伤害，会伤及自己，同一角色多个碰撞体只算一次。

道具箱默认位于横坐标9、30、54，消耗品点位于22、47、69，高度均为2.6。每个消耗品点75%概率生成，生命针剂／炸药束权重3:1；配置集中在`HunterItemLoot2D`。箱子优先等概率选一个未满的常规工具，补充该工具配置的固定次数（当前1次），不会一次补满所有工具；匕首不参与补给。工具全满且消耗品有空栏才抽取消耗品，散落消耗品只检查自己的栏位。靠近1.6单位且无遮挡按E领取，先保存再发布，保存失败保留物品和原补给结果，可按E重试。任务交互优先，其余就近选择未用点位，附近已用箱子不会挡住其他未领取物品；正在使用道具时不能拾取。

营地显示所选猎人的等级、升级进度、技能点，以及独立的账号等级／升级进度／累计经验和退役人数。满级点击“满级退役”进入确认窗口，预览账号等级变化，可取消；确认后永久移除该猎人，返还所有已装备武器及剩余道具并获得500账号经验，角色技能点不继承。仅在营地允许退役；仓库无法容纳道具时禁止退役，保存失败不移除猎人、不发经验或等级，可以重试。账号采用验证曲线：1级起，每1000经验升一级，100级封顶，满级后原累计经验仍保留；当前仅提供等级与进度，不自动提升战斗属性或发放解锁奖励。账号等级由已有经验推导，存档仍为版本10，旧档无需新增字段。

一次性技能“应急包扎”：营地2点购买／手动移除返还1点，也进入技能卡随机池；行动中按G瞬间恢复50生命，不超过最大生命。使用前先保存技能移除，成功后才治疗，不返还技能点，不更改道具次数、弹药、体力或其他被动加成。满血、暂停、受伤、攻击、换弹、医疗／投掷准备、调查视角、死亡和营地均不可使用；失败保留技能与原生命，提示按G重试。用过的同一份不能重复触发，另买或另捡一份可再用一次；未使用的技能撤离保留，永久死亡随猎人遗失且不能用来复活。局内HUD仅在持有时显示G提示。草案未指定具体主动效果，这个名称、2点价格和50治疗量为验证示例。

存档内部版本为10，继续使用原`career-v1.json`路径。首次成功迁移保留原文件为`.bak`；版本1～9猎人统一迁移为招募模板，保留原有合法双枪和技能，不猜测其获取来源。版本9保留自定义血段，版本1～8初始化四段25；版本6～9的仓库和携带道具（含剩余次数）、技能和成长原样保留。版本5及更早账号增加空仓库道具和猎人道具列表，已有技能、局内获取价值和成长／账号数据保留。版本3初始化局内获取记录为0；版本2初始化空技能列表；版本1没有成长记录，从1级／0经验／0技能点开始，不追溯补发过往经验。旧存档中未撤离的猎人仍按永久死亡规则结算。之后每次成功保存按原规则更新`.bak`。

`LevelSession2D` 管理 Loading → Ready（营地）→ Playing → Paused / Dead / Won；消耗死灵法师技能后进入Reviving，再恢复Playing。返回营地进入Respawning，重置任务和场景，等待出生区地形后进入Ready。每次StartRun读取所选猎人的装备，存档成功后才开放操作。`TrainingMode`默认关闭，仅旧流程回归显式启用以保留检查点复活测试；正式场景在没有可消耗复活技能时使用永久死亡。

守卫沿用地图对象池的稳定实体 ID 与生命状态；停用和回池会清理目标、速度、攻击计时与战斗驻留标记。角色的受伤、死亡事件由 `SkillActor2D` 提供；原整合示例不设置无敌时间，保留其原有受击规则。

地面的 Solid Tilemap 使用静态 `CompositeCollider2D` 合并相邻格子，处理玩家和守卫开启连续碰撞检测时被内部格子接缝卡住的问题。区块或格子变化后同步更新碰撞几何；OneWay 单向平台仍保持原 `TilemapCollider2D + PlatformEffector2D` 规则。此修复不改变关卡布局、巡逻速度或攻击参数，细节见 [地图碰撞说明](../Assets/_Project/Modules/Map2D/README.md#碰撞与预览)。

**创建缺失资源并设为打包入口** 菜单只补建缺失资源，不覆盖已调整的关卡、预制体和技能。正常修改直接保存对应资产；不必重新生成。

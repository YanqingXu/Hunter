# BigWorld

Unity 2022.3.62f3c1 的 2D 横版项目，已迁入课程原版 YouYouFramework 并接通地图、技能、共享对象池和横版玩法。当前为纯 C# + HybridCLR：保留 18 个非 Lua 管理器，原脚本业务已迁为 C#，xLua 源码、绑定、脚本与原生库已移除。

**原框架入口：`Assets/YouYouFramework/GameEntry.cs`；底层管理器：`Assets/YouYouFramework/Managers`。** 当前运行的是 `YouYou.GameEntry`，原精简 `Packages/com.youyou.framework` 已从活动依赖移出。

用 Unity Hub 打开本目录。游戏入口：**Tools → BigWorld → 正式关卡 → 打开边境试炼**，然后 Play。修改资源目录、UI 配置或表格后，先运行 **Tools → BigWorld → 2D 框架 → 生成原框架运行内容**。发布入口：**Tools → BigWorld → 打包 → Windows 64 位（发布）**，会自动构建原格式资源包和完整 ZIP。

边境试炼包含角色移动 / 跳跃容错、守卫巡逻追击与攻击、受伤无敌和击退、营地整备、永久死亡与本地存档。可调查线索、猎杀Boss并携赏金撤离，也可刷怪练级后不带赏金直接撤离；两条路线均需在右侧出口无敌人争夺时连续等待10秒。只有实际携带赏金才获得对应资金，未击杀Boss不会因为撤离成功而获得Boss经验。Cinemachine 2D 跟随、地图边界限制和原有技能流程保留。

每局4个区域分别随机刷新1～2条线索，调查任意3条即可定位Boss。地图栏逐区置灰并显示当前位置，线索位置只在按住V／触控调查时显现；也可直接找到并击杀Boss。拾取赏金后地图才显示边缘撤离点，掉落赏金不会忘记出口；重新出战重置随机布局。桌面与触控界面均保留区域地图。

Hunter 策划已接入基础战斗、赏金撤离、营地整备和猎人成长。进入游戏先在营地招募／选择猎人、购买／装卸武器，再开始行动。成功撤离后赏金与经验一起入账；死亡、确认放弃或行动中退出游戏会永久失去出战猎人和携带装备，仓库及其他猎人保留。初始资金500、一个双枪猎人及仓库备用双枪；最多5名猎人，名单为空时可领取救济。

营地“血段设置”可为每名猎人分别组合25／50血段：拆分50或合并相邻两个25，总生命保持100。调整先作为草稿，保存后下次出战生效，取消不修改档案；写入失败可保留草稿重试。实际HUD和脱战恢复使用该猎人的血段节点，出战中不能修改；触控版提供更大的编辑按钮。

猎人从1级开始，每100经验升一级并获得1技能点，10级满级后可以在营地确认退役：转换500账号经验，携带武器返还仓库。线索25经验、小怪20经验（含第二波）、Boss100经验、撤离100经验，仅成功撤离入账；上述数值为验证配置。营地点击“猎人技能”可购买或移除格斗节能（1点）、快速装填（2点）、稳定瞄准（3点），下次出战分别降低近战体力消耗、换弹时间、射击间隔。地图三个刷新点有概率生成青色技能卡，靠近按E拾取后立即生效，不消耗／直接增加技能点，不补满弹药。已学技能不会重复获取；撤离保留、永久阵亡丢失。所有技能在营地主动移除时统一返还：1点全返，其余一半向下取整。

新增死亡技能“死灵法师”（4点，也可局内拾取）：致死时自动消耗，恢复50%生命并原地复活，3秒内不会触发普通守卫、Boss或第二波怪物警戒；这不是无敌，暂停会冻结倒计时。其他技能、体力、弹药和剩余道具保留，赏金掉落原地，坠出地图则回到最近落脚点。消耗先保存，失败时冻结并提供重试；触发不返还点数，每份技能只复活一次，重新获取另一份后可再次触发。放弃或中断行动不触发复活。

营地“道具整备”可购买和装备匕首、急救包、飞刀、生命针剂及炸药束，每位猎人有2个常规工具栏与2个消耗品栏。Q切换、F使用；医疗和投掷准备时移速减半，受伤打断且保留次数，暂停冻结进度。工具耗尽保留，消耗品用完移除，剩余次数随撤离、卸装和再次出战保留；永久死亡遗失，退役归还仓库。炸药束会被墙体遮挡，也能伤到自己。

地图蓝色道具补给箱可按E领取：随机为一个次数未满的工具增加1次，工具全满后才向空消耗品栏按权重补发生命针剂／炸药束。橙色散落消耗品可直接拾取进空栏。满栏保留、成功变灰，每局每点只领取一次；地图卸载重载不会刷新，保存失败可原地重试。

断桥后的灰蓝色弹药柜可立即打开，中段棕色封锁弹药柜需要静止等待3秒。靠近按E，触控可点附近变为“交互”的奔跑键；开柜后再次交互领取弹药。等待时移动、瞄准、攻击、道具等操作会中断，重新尝试从零计时；暂停只冻结计时。受伤、死亡、失焦或失去交互条件会取消，已开启及已领取状态在本局跨区后保留，新局重置。柜体目前使用现有标记贴图组合显示。

中段高台左侧增加固定梯子，站立靠近按E或触控“交互”上梯。W/S或摇杆上下攀爬，左右主方向在通道无阻挡时离梯；到顶自动尝试登上高台，出口受阻可向下返回。梯子上攻击、道具、跳跃、匍匐和调查操作无效，不消耗相关资源；暂停、失焦和挂起清除方向并保持依附。受伤、死亡、停用和位置重置会离梯并恢复原重力。移动和上下出口检查完整角色碰撞盒，墙体及其他实体角色均会阻挡。

道具常规技能“投球好手”需2技能点，增加50%投掷距离（飞刀8→12、炸药束6→9），营地移除返还1点，也可局内拾取立即生效。每次投掷单独记录当时的效果，已出手物体不会因后续拾取技能改变射程；伤害、准备时间和使用次数不变。技能菜单支持滚动和键盘自动显示选中行，局内HUD显示投掷距离。

飞刀与炸药跟随二维瞄准，可向上、下或斜向投掷。按F开始准备时固定这一投的方向和姿态高度，HUD显示“方向已锁定”；随后移动会改变出手位置，转向只影响下一投。匍匐降低出手高度且不能向下投掷；弧线仍向世界上方隆起，碰撞扫掠、炸药引信、遮挡和次数保存保持原规则。

撤离区附近x70／72.5／75有三个红色爆炸桶。子弹命中后闪烁，1.5秒后爆炸；炸药或邻桶爆炸会立即引爆，近战和飞刀不点燃。爆炸可伤到自己，固体墙能阻断传播；爆炸后留下无碰撞残骸。离开到区块卸载时冻结引信，回来继续剩余时间，已爆桶不会刷新；重新出战才重建。

x36附近有蓝色护甲精英，受到的伤害减少50%；x59附近的青色召唤者没有普攻，会召唤拥有独立生命的绿色单位。击杀召唤物，或离开双方警戒范围3秒，会使召唤技能进入6秒冷却；击杀本体立即清理召唤物。拾取Boss赏金后两类精英各追加一只，保留第一波存活者并扩大警戒范围；精英和召唤物都能阻挡出口，精英每只20经验，召唤物不提供可重复刷取的击杀经验。

Boss警戒时使用近战挥砍与固定方向能量弹；生命降到100／50时进入3秒狂暴，立即预警范围冲击，并可使用短距冲刺。黄色弧线、瞄准线、圆环和矩形表示四种攻击前摇；绕到挥砍背后、离开弹道或冲击范围可躲避。冲刺不会穿过实体墙或跨越断桥，暂停冻结技能，失去目标、卸载或死亡会清理攻击效果。具体技能数值为当前验证配置。

普通守卫与第二波士兵失去视线／目标后会停下观察1秒，再恢复巡逻；重新看到玩家立即追击。等待期间取消攻击，不能隔墙命中。第二波士兵保留更大的警戒范围，并使用巡逻2、追击3的速度；精英也使用相同的1秒警戒记忆，召唤物的脱离消失机制仍独立计时。

一次性技能“应急包扎”需2技能点，行动中按G恢复50生命（最多到生命上限），成功使用后移除且不返还技能点。满血、暂停、受伤、攻击、换弹、道具准备、调查视角和死亡时不消耗；保存失败保留技能且不治疗，可按G重试。营地手动移除返还1点，局内拾取可立即使用，消耗后获得另一份可再次使用。具体名称、价格与治疗量是验证配置，草案只规定一次性技能使用后移除。

A/D行走，W/S或上下方向键瞄准，可组合为斜向；松开方向输入停下并保持最后瞄准方向。青色准星显示当前瞄准，J可长按连续射击，每枪在接受操作时固定方向；随后转向影响下一枪。移动仍只沿水平方向，K近战沿角色面朝，玩家碰撞体不随瞄准旋转。C在地面切换匍匐，走速和碰撞高度减半，Shift不能加速；仅可朝当前面向的前方至上方瞄准。低顶下起身和跳跃会被阻挡；空间足够时跳跃先起身，医疗准备减速继续叠加。移动设备自动显示摇杆和动作按钮；桌面编辑器可在Game HUD 2D上启用ForceTouchControls预览。摇杆控制水平移动与二维瞄准，奔跑／匍匐为切换按钮，射击／跳跃支持长按，其余按钮点按。按住“调查”时摇杆移动视角，松开后可交互；暂停、失焦或旋转画面会清除原手势，需要重新按下。状态和按钮避开屏幕安全区，退出触控模式恢复原键盘设置；实体移动设备和移动包尚未验收。

Shift 奔跑，空格跳跃，K 近战，R 换弹，1／2切换携带的武器，E交互，G应急包扎；按住V并用方向键寻找蓝色线索，松开后调查。存档位于 `Application.persistentDataPath/Hunter/career-v1.json`，每次营地操作、出战、技能拾取、复活／一次性技能消耗、有限次数道具消耗、道具补给／拾取及结算自动保存。文件名保持兼容，内部格式已升级到版本10，版本1～9自动迁移并保留原文件备份；旧角色统一使用招募模板以保留原有双枪和技能，版本9保留自定义血段，更早版本初始化四段25血段，版本1～5按此前规则初始化空道具栏。最新测试结果、独立发布包及人工验收状态见 [批次说明](Docs/Hunter-Implementation.md)。

营地有招募／救济两种猎人模板：招募100资金、武器负重3、携带技能价值14；救济仅名单为空时领取，武器负重2、技能价值10，可携带一把步枪或一把手枪。两者共享100生命及基础移动／体力配置，各自保存成长、技能和血段。技能携带量按当前已学技能的价格合计，区别于可用技能点；移除或消耗技能后释放容量，满容量时购买和拾取都会保留原来的点数或卡片。数值仍为验证配置。

步枪的默认弹药可穿过最多两件木掩体，每穿一件保留75%伤害（25→18.75→14.0625）；手枪会被木掩体挡住，普通地形始终阻挡。地图x30.5／32.5的木掩体可用奔跑加跳跃越过。默认弹药配置支持每发弹丸数、每颗伤害、散射角、距离及可穿道具种类；多颗弹丸只扣一发弹药，各自计算碰撞和减伤，切枪不影响已出手弹丸。正式配置仍为单弹丸，三弹丸配置已通过真实场景验收。

C# 热更新使用 **HybridCLR 8.15.0 / IL2CPP**。主包只包含 AOT 启动场景，原框架和 2D 游戏代码作为热更 DLL 加载；发布补丁使用 `Tools/Build-HotUpdatePatch.ps1`，对应 AOT 基线保存在 `Builds/HotUpdate/Bases`。

账号等级已接入营地：显示等级、当前级进度、累计经验和退役人数，确认退役可预览等级变化。验证曲线为每1000账号经验升一级、最高100级；退役仍增加500经验，满级后累计经验保留，猎人成长与账号成长独立。等级由原累计经验计算，存档版本10保持兼容；不自动增加战斗数值或发放未配置的解锁奖励。最新1755项Unity完整验收通过，独立EXE与实体设备验收状态仍见批次记录。

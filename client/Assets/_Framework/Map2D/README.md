# 横版 2D 地图编辑器

入口：**Tools → BigWorld → 2D 地图编辑器**，也可使用 **Window → BigWorld → 2D Map Editor**。

地图位于 XY 平面，左下角为 `(0, 0)`。地形与物件分别保存，同一格可以同时有地面和一个物件。

## 开始使用

1. 打开编辑器，默认载入 `Assets/_Examples/Map2D/Data/PlatformExample.asset` 示例地图。
2. 左侧选择“地形”或“物件”，再选择类型。在中间画布绘制。
3. 点击“保存”或按 **Ctrl+S**。双击地图资产可以再次打开它。
4. 点击“生成到场景”，在当前场景中生成一个带 `GridMapRenderer` 的地图对象。Scene 窗口会切换到 2D 并定位地图。
5. **场景需单独保存**。运行时渲染器会读取所关联的地图资产。

点击“新建地图”创建空白地图；“另存为”复制地图布局，新旧地图仍共享类型配置。

比例约定：默认每格为 1 个世界单位，地图图块使用 16 Pixels Per Unit。Rasta 的角色精灵和动画也统一为 16 Pixels Per Unit，站立可见高度约 1.4 格；新增同角色动作时应沿用相同比例。

## 分区运行与 NPC / 怪物

编辑器仍显示整张地图。“生成到场景”保留完整编辑预览，进入游戏后默认启用附近区域加载：原来的六个 Tilemap 只保存当前需要的区块格子与碰撞，不会给每个地面格子创建一个物体。地图布局和类型资产仍整份驻留；本版是运行对象与碰撞的分区管理，尚不包含 Addressables 或磁盘资源分块读取。

打包时会自动清除构建场景副本中的整图预览格子和碰撞，防止游戏启动时先载入完整预览。编辑用的场景文件与地图资产保留原样，运行时再按附近区块建立内容；未启用分区加载的地图保持原流程。

1. 点击“生成到场景”，把地图编辑器右侧的“跟随对象（玩家）”设置为玩家 Transform。留空时尝试 `Player` 标签，再使用主相机；两者都没有时使用地图出生点附近。
2. 点击“查看分区运行设置”，可调整每块边长、预加载半径、卸载缓冲、每帧区块数和时间预算。默认每块 32 × 32 格，每帧最多处理 2 块；跟随目标所在区块先同步准备碰撞。时间预算在区块操作间检查，不能中断一次 Unity Tilemap / 碰撞更新，需在目标设备上测量并调整。
3. 点击顶部“NPC / 怪物…”，新增生成点，选择角色预制体、类别、数量、水平间距、生命值和死亡刷新时间。点击“到地图画布上选择位置”，再点击格子定位。刷新时间为 0 表示本次存档中死亡后不再刷新；超出地图的生成位置会跳过。保存地图和场景。
4. 选择地图场景对象，在“角色 / 物件加载设置”中配置激活距离、回收距离、活动上限和每帧生成请求数。旧场景可以在地图组件 Inspector 点击“添加角色 / 物件加载设置”；未添加时运行会使用默认值。

角色和格子绑定的预制体交给项目现有对象池。离开回收范围后保留位置、生命值、死亡、宝箱打开和点燃状态，返回时恢复；物体实际生成前先等待所在格子的地形就绪。加载和卸载使用不同距离，避免边界反复生成。活动角色的脚下区块会保留；游戏脚本可设置 `MapStreamedEntity.CombatPinned`，避免追击或战斗时被回收。

生成点属于地图，房屋模板仍只保存格子布局；先放置房屋，再配置其中的角色。生成器负责创建、回收与状态接入，NPC 的移动、寻路、战斗，以及宝箱交互、爆炸和火焰表现仍由预制体的游戏脚本提供。

运行时用 `renderer.RuntimeState.SetCell(x, y, type, layer)` 修改格子，会局部更新当前已加载区域；不要直接修改地图资产来记录游戏进度。`DestroyCell` / `IgniteCell` 会检查格子类型的可销毁 / 可点燃配置。游戏脚本可通过 `MapStreamedEntity.TakeDamage`、`Kill`、`MarkOpened`、`Ignite` 同步状态。格子绑定的实体同样遵循类型能力，销毁时一并移除该格子的显示与碰撞；独立生成点的角色使用生成点生命值和刷新规则。

区块卸载后的状态保留在本次地图会话中。要跨游戏进程保存，用 `renderer.SaveRuntimeState()` 获取 JSON，再写入游戏存档；用 `renderer.LoadRuntimeState(json)` 恢复。编辑器运行时在地图组件 Inspector 也提供“导出运行存档 / 载入运行存档”。读档会校验地图标识、尺寸和数据；死亡刷新计时保存为剩余游戏时间。格子类型的“类型标识”须非空且互不重复，否则会拒绝保存或读档并指出冲突。运行时新增、源地图中不存在的格子类型，读档时应通过 `additionalTypes` 提供。角色预制体若有额外业务状态，应在自己的存档系统里一起处理。

编辑器会维护地图的存档标识：“另存为”或在 Project 复制地图后，新地图使用独立标识；移动、重命名保持标识。地图扩缩尺寸后，旧尺寸存档会被拒绝，避免把旧坐标状态套到新布局中。

瞬间传送时，应先移动加载目标并等待落点及角色脚下所需格子 `IsCellLoaded(...)` 返回 true，再恢复角色物理/移动。对象池的异步创建与回收需要驱动持续运行，不能提前销毁池驱动或它的缓存节点。

## 九种默认类型

| 类型 | 所属层 | 默认格子碰撞 | 标签 | 用途 |
| --- | --- | --- | --- | --- |
| 地面 | 地形 | 实体 | `ground` | 生成地板和墙壁 |
| 尖刺 | 物件 | 无 | `hazard` | 标记危险位置，可绑定伤害预制体 |
| 出生点 | 物件 | 无 | `spawn` | 标记出生位置，允许多个出生点 |
| 炸药桶 | 物件 | 无 | `explosive` | 可绑定带受击、爆炸行为的预制体 |
| 宝箱 | 物件 | 无 | `chest` | 可绑定带交互、掉落行为的预制体 |
| 墙 | 地形 | 实体 | `wall` | 建筑外墙、屋顶和楼板 |
| 窗户 | 物件 | 无 | `window` | 建筑窗户，初始可被销毁 |
| 木门 | 物件 | 实体 | `door` | 建筑入口，初始可被销毁、可被点燃 |
| 楼梯 | 地形 | 单向平台 | `stairs` | 多格逐级上升的阶梯 |

九种默认类型附带原创的简单像素占位图，可直接替换精灵。新窗户覆盖“可被销毁”为 `true`；新木门覆盖“可被销毁”和“可被点燃”为 `true`；其余使用公共属性的初始默认值 `false`。补充默认资源不会重置已有类型的配置。

**地图编辑器负责摆放和配置，不包含玩家、伤害结算、爆炸或开箱系统**；这些行为由项目的游戏脚本或绑定的预制体实现。出生点不会自动生成玩家；门不会自动开关，楼梯提供可配置的格子碰撞，不包含角色攀爬或行走控制。

## 编辑操作

| 操作 | 使用方式 |
| --- | --- |
| 画笔 | `B`，按住左键连续绘制；笔刷 1～16 格 |
| 橡皮 | `E`，或直接按住右键；只清除当前层 |
| 矩形 | `R`，拖动起点和终点；支持“空心” |
| 区域填充 | `F`，替换当前层四方向连通的相同类型区域，包括空格 |
| 吸管 | `I`，从当前层拾取已有类型；拾取空格后切换橡皮 |
| 平移、缩放 | 点击工具栏“手形 H”（或按 `H`），按住左键拖动画布，按 `B` 返回画笔；也支持中键拖动或 Alt+左键。滚轮缩放，“适应画布”显示全图 |
| 撤销、重做 | `Ctrl+Z` / `Ctrl+Y` 或 `Ctrl+Shift+Z`；一次连续笔画作为一步 |
| 保存 | 顶部“保存”或 `Ctrl+S`，同时保存引用的类型配置 |

宽高范围为 1～256 格。调整大小会保留左下角重叠区域的两层数据；缩小时确认裁剪，可撤销。原点与每格尺寸控制场景中的位置和大小，不改变格子坐标。

切换地图时会保存当前地图；正常关闭窗口时也会保存。编辑器重编译期间不强制保存，请养成按“保存”的习惯。

## 随机生成地图区域

当前暂时停用：工具栏按钮和菜单入口已隐藏，已打开的随机窗口也无法生成。代码保留，以下为恢复后的功能说明。恢复时，在 Unity 的 Scripting Define Symbols 中加入 `BIGWORLD_MAP_RANDOM_GENERATION`。

选择地图，点击顶部“随机生成…”打开配置窗口，也可使用 **Tools → BigWorld → 地图 → 随机生成地图**。填写区域左下角的 `X / Y` 和宽度、高度，或点击“使用整张地图”。主画布会用橙色边框标出有效区域。区域必须完整位于地图边界内；区域外的地形和物件保持原样。

勾选“生成起伏地面和悬空平台”时，会生成地形与物件，需要区域至少有两行；取消勾选后，仅重新摆放物件，保留已有地形，利用现有地面上的空位摆放物件，包括由区域下方紧邻地形提供支撑的位置。

选择要使用的地形、炸药桶和宝箱类型；桶、箱和启用的出生点须使用不同的物件类型。需要出生点时勾选“生成 1 个出生点”，并选择出生点类型。炸药桶、宝箱数量分别填写：

| 输入 | 含义 |
| --- | --- |
| 留空 | 按可用位置随机生成数量 |
| `0` | 不生成该类物件 |
| 非负整数 | 生成准确数量；容量不足时整次生成不提交 |

指定数量优先占用可用位置，随机数量使用剩余位置。桶、箱和出生点不会放在同一格。这里的数量指生成结束后该区域内的数量，不是在旧物件上追加。

**生成会替换区域内原有物件**，包括尖刺、出生点和自定义物件；只重新放置此次配置选择的物件。生成地形模式还会替换区域内原有地形；仅物件模式保持地形不变。

种子留空时使用随机种子，生成结果会显示本次种子，也可点击“使用上次种子”复用。相同种子、配置和地图条件可以复现结果。确认配置后点击“随机生成并替换区域”；输入不合法或可用位置不足时会提示原因，地图保持原样。成功生成作为一次编辑操作，按 `Ctrl+Z` 即可整体撤销，之后也可以继续用画笔调整。点击“保存地图”或按 `Ctrl+S` 保存结果。

## 房屋模板

左侧切换到“房屋模板”，可使用小木屋（9 × 7）、双层住宅（13 × 11）和仓库（15 × 8）。模板包含镂空房间、门窗、楼板和部分储物；双层住宅与仓库还使用多格楼梯连接不同高度。模板和格子类型都可以继续修改。

小木屋和双层住宅的入口为两格高；地图中已放置的旧房屋需重新放置，才会采用更新后的入口。

将模板拖到画布，或选中模板后在画布点击放置；鼠标所在格是模板的**左下角锚点**。可开启水平镜像，模板必须完整位于地图内。默认勾选“覆盖房屋范围内的空白格”，会用模板两层数据替换整个矩形，模板中的空格也会清除目标格；取消后，各层只覆盖模板中的非空格。放置可以撤销，按 **Esc** 或右键结束放置。

点击“编辑选中房屋”进入模板的布局子资产，用相同画笔修改并保存，然后返回原地图。已放置的房屋保留当时的布局，不会随模板后续修改而改变；它们仍共享格子类型，所以类型外观、碰撞和属性的修改会一起生效。

点击“从地图区域保存房屋…”，填写矩形区域，将现有地图两层布局保存为独立模板以便复用。默认保存目录为 `Assets/_Game/Data/Maps/Structures`，也可以另选 Assets 内的位置；房屋库会扫描整个 Assets。保存模板不会改动原地图，也不会覆盖同名资源。

## 新增类型与外观

在左侧点击“新增格子类型”，保存到 `Data/Maps/TileTypes`。类型自动加入当前面板；右侧可修改名称、颜色、精灵、运行时预制体和格子碰撞。完整 Inspector 中还可设置默认层、标签、类型标识和通行查询属性。

也可通过 Project 右键 **Create → BigWorld → 2D Map → Tile Type / Palette / Map** 创建资产。将类型拖入类型面板后即可绘制。

- 类型是共享的资产。改一个类型的外观或碰撞，会影响所有引用它的地图。
- 改类型的默认层不会迁移地图里已绘制的格子；新笔画按当前类型的默认层放置。
- 地图使用资产引用识别类型，改显示名称不会破坏布局。移除面板条目不会删除格子，删除类型资产会使对应引用丢失。
- 自定义精灵按 **一单位一格** 设置 Pixels Per Unit。地图渲染器整体缩放，使精灵和碰撞随“每格尺寸”一起改变。
- 未指定精灵时使用颜色方块。物件层排序高于地形层。
- 预制体在运行时实例化；编辑时使用类型精灵预览。预制体自身可带碰撞器，格子碰撞则由类型单独配置；木门默认使用实体格子碰撞。

## 格子类型的扩展属性

地形和物件类型默认共用 `Assets/_Game/Data/Maps/TileProperties.asset`（`MapTilePropertySchema`）。这份定义表列出属性的名称、稳定标识、值类型和默认值；每种 `MapTileType` 只保存自己需要覆盖的值。新增一个定义后，使用这份定义表的所有类型都能看到它，不需要给每种类型重复添加。

内置“可被销毁”和“可被点燃”两个布尔属性，初始默认值均为 `false`。已有地图和类型无需改布局，也不会因此自动变成可销毁或可点燃。

1. 选择格子类型，在地图编辑器右侧或类型 Inspector 中查看属性的有效值。
2. 直接修改某项数值，为当前类型创建覆盖；点击“恢复”后，这个类型重新使用定义表的默认值。尚未覆盖的项目旁会显示“默认”。
3. 打开“管理公共属性（新增 / 修改）”，新增属性，选择开关（布尔值）、整数、小数或文本，并设置默认值。也可从 **Tools → BigWorld → 地图 → 管理公共格子属性** 打开定义表。
4. 保存修改。改变共享默认值会影响未覆盖该项的类型；已有覆盖保持各自的值。

未选择地图时，也可以用“保存”或 `Ctrl+S` 保存类型和公共属性配置。在编辑器中切换当前类型时，会先保存原类型及其属性配置；公共属性窗口也有独立的“保存”按钮。

属性标识以英文字母开头，后续可使用字母、数字和下划线；创建后只读，区分大小写。显示名称可以修改，不影响已保存的覆盖值和代码查询。自定义属性更改值类型前会提示：旧类型覆盖会保留，但在类型不匹配时不生效，也不会自动转换；如果随后为该类型填写新的覆盖值，会替换这个标识原有的覆盖。删除定义后，该属性停止参与查询；内置两个属性的标识和值类型不能更改，也不能删除，但可以修改它们的默认值。

首次打开编辑器时，已有类型中尚未指定定义表的资产会关联默认定义表；新建类型也自动关联。已经关联了其他定义表的类型保留原配置。地图仍使用原类型资产引用，不需要重新绘制。

这些属性属于**格子类型**：修改“地面”的属性，会影响所有引用该地面类型的格子。若需要某一块地面有不同能力，请建立另一个类型；单个格子的当前血量、燃烧进度等运行状态应由游戏逻辑单独保存。

“可被销毁”“可被点燃”表示供游戏逻辑读取的能力配置，不会自动实现受伤、移除格子、起火或火焰传播。其他自定义属性同样由对应的游戏系统解释。

## 碰撞与预览

类型支持“无碰撞”“实体”“单向平台”。实体地形使用 `TilemapCollider2D`；单向平台位于独立 Tilemap，配合 `PlatformEffector2D` 从下方穿过、从上方落地。使用单向平台时，角色应使用 Unity 2D 物理组件，并保证项目碰撞矩阵允许对应层交互。

“生成到场景”会复用当前场景中已关联此地图的渲染器；也可以把指定渲染器拖入右侧预览字段。连续绘制完成后可自动更新这个预览。多个地图对象引用同一地图时，其他实例可在 Inspector 中点击“重新生成地图”。

生成的六个 Tilemap 分别对应两种数据层和三种碰撞模式。它们是由地图资产派生的内容，请在地图编辑器中改格子，避免直接修改生成的 Tilemap 后被重建覆盖。清空场景预览保留资产与用户组件，运行时仍按地图数据重建。

## 文件位置

- `Assets/_Framework/Map2D/Runtime`：地图、类型数据与场景渲染组件。
- `Assets/_Framework/Map2D/Editor`：编辑窗口、绘制操作、Inspector 与默认资源创建。
- `Assets/_Game/Data/Maps`：地图与类型面板；`TileTypes` 存放类型资产。
- `Assets/_Game/Data/Maps/TileProperties.asset`：默认共享属性定义与默认值。
- `Assets/_Game/Data/Maps/Structures`：默认房屋模板及各自的布局子资产。
- `Assets/_Game/Art/MapTiles`：九种类型的像素占位图。
- 项目根目录 `Tests/Map2D/Editor`：在独立项目副本中执行的验证代码。
- 项目根目录 `TestResults/Map2D`：实际验证结果。

模块沿用项目默认程序集，Editor 代码不会进入游戏构建；运行物体复用项目 `Framework/Pooling` 对象池，无额外包依赖。

## 游戏逻辑读取示例

```csharp
using BigWorld.Map2D;
using UnityEngine;

// renderer 是场景中的 GridMapRenderer。
Vector2Int cell = renderer.WorldToCell(worldPosition);
renderer.TryGetCell(worldPosition, out MapTileType terrain, MapLayer.Terrain);
renderer.TryGetCell(worldPosition, out MapTileType item, MapLayer.Objects);
if (item != null && item.HasTag("spawn"))
{
    Vector3 spawnPosition = renderer.CellToWorldCenter(cell.x, cell.y);
    // 交给你的玩家生成逻辑。
}
```

`TryGetCell` 和 `IsWalkable` 在运行时读取当前地图状态，包括尚未加载的区块。`IsWalkable` 是格子级的通行查询，不能代替横版角色的跳跃判定、寻路或实际物理碰撞。游戏中通过 `renderer.RuntimeState.SetCell(...)` 修改当前关卡，已加载的格子会局部更新，无需整图 `Rebuild`；源地图资产保持原样。

内置能力可通过 `type.CanBeDestroyed`、`type.CanBeIgnited` 读取，对应稳定标识 `destructible`、`flammable`。自定义属性使用 `GetBool`、`GetInt`、`GetNumber`、`GetText` 按标识读取；结果优先使用值类型匹配的覆盖，否则使用共享默认值。没有定义、定义与所用读取方法的值类型不匹配，或尚未关联定义表时，返回调用者提供的后备值；省略后备值则返回 `false`、`0`、`0f` 或空文本。

例如，在公共属性中新增整数属性 `max_health`、小数属性 `burn_seconds`、文本属性 `drop_table` 后，可以读取：

```csharp
bool destructible = type.CanBeDestroyed;
bool flammable = type.CanBeIgnited;
int maxHealth = type.GetInt("max_health", 100);
float burnSeconds = type.GetNumber("burn_seconds", 3f);
string dropTable = type.GetText("drop_table", "none");
```

这里的 `type` 是查到的非空 `MapTileType`；后备值只用于没有可用定义的情况，不会覆盖定义表中已配置的默认值。

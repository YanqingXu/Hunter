# 2D 横版技能编辑器

已在原编辑器中加入可切换的 2D 模式。原有技能默认保持 3D，2D 技能使用 XY 平面：X 为左右、Y 为上下，默认朝右。

## 先运行示例

1. 用 Unity 打开 `E:\BaiduNetdiskDownload\skillBuild`。
2. 在 Project 中打开 `Assets/SkillEditorKit/Samples/TwoD/Skill2DDemo.unity`。
3. 点 Play：A/D 或左右方向键移动和转身，按住 J 射击，K 近战。目标受击时闪白。

示例中的像素角色、子弹和动画是测试素材，可替换为你自己的资源。此场景用于验证技能，不包含跳跃、敌人 AI 或完整角色控制器。

## 编辑自己的技能

1. 菜单 **技能编辑器（独立版）→ 打开工作台**。
2. 打开示例 `Shoot2D.asset`（射击）或 `Melee2D.asset`（近战）。它们都位于 `Samples/TwoD`。
3. 在“预览设置”选择 `Player2D.prefab`。
4. “技能信息”中的“游戏空间”设为 **2D 横版（XY 平面）**；新建技能窗口也可以直接选 2D。
5. 拖动时间轴，查看动画、攻击矩形和子弹轨迹。“技能信息”内有“Scene 切换 2D 视角”按钮。
6. 动画片段中换上你的 `.anim`；投射物片段中换上带 SpriteRenderer 的子弹预制体，再调整发射帧、速度、射程与伤害。

动画里的 SpriteRenderer 路径必须与角色预制体一致。例如示例动画绑定根物体下的 `Visual`，你的动画若绑定在根物体，就要使用相应的角色层级。像素逐帧动画通常关闭 Apply Root Motion。`.aseprite` 原文件仍需先导入或导出为 Unity 能读取的精灵与 AnimationClip。

## 已接入的 2D 功能

- 矩形、圆形、扇形 / 半圆 / 整圆攻击；矩形使用 X/Y 尺寸，Z 不参与碰撞。
- 子弹直线、散射、抛物线、追踪；在 XY 平面运动，使用 Collider2D 命中。
- 矩形 / 圆形飞行攻击和子弹的帧间扫掠，减少快速移动漏判。
- 左右朝向、阵营与层筛选、重复命中控制、穿透上限、2D 墙壁阻挡。
- SpriteRenderer 逐帧动画播放、时间轴预览、2D 范围轮廓和独立命中测试。
- SkillWeapon 的 Collider2D 触发器入口。

## 角色和目标接入

示例 `SkillDemoActor2D` 展示了完整的初始化顺序：初始化 SkillAnimationPlayer，将角色传给 SkillPlayer.Init，再设置 SkillBehaviourBase。正式项目可以把这一小段接入自己的角色脚本。

- 角色根物体：Animator、SkillAnimationPlayer、SkillPlayer；精灵放根物体或子物体均可，动画绑定需匹配。
- 角色实现 ISkillActor；被攻击对象实现 ISkillHitTarget。使用“敌方 / 友方”规则时，双方还需要 ISkillTeam。
- 目标添加 BoxCollider2D、CircleCollider2D 等；目标所在层必须包含在 SkillPlayer.attackDetectionLayer 中。
- 示例使用角色阵营 1、目标阵营 2、目标层 30。新项目应按自己的层设置修改。
- 碰撞回调负责把伤害交给游戏，生命、击退、冷却、资源消耗等仍由项目实现；示例只扣除生命并闪白。

**转身：** 默认自动读取 SpriteRenderer.flipX 和 Transform 镜像；复杂角色可加 SkillFacing2D，并在转身时调用 `SetFacing(-1)` 或 `SetFacing(1)`。该组件可以指定用于判断朝向的 SpriteRenderer。

**枪口挂点：** 2D 挂点的本地 +X（红色轴）为发射方向。flipX 只翻转精灵，不会移动或旋转挂点；使用枪口挂点时，需要同步镜像挂点父物体。示例使用“角色脚下 + 前移 / 上移”，无需挂点。

**特效：** 2D 特效位置的 X 沿角色朝向、Y 沿世界上方；子弹外观朝 +X 制作。子弹预制体只提供外观，它自己的碰撞体和移动脚本会被关闭，技能系统统一控制运动与命中。

**武器触发器：** 在 SkillWeapon 的 Detection Collider 2D 中指定触发器，并按 Unity 2D 物理规则配置 Rigidbody2D。独立命中测试仍跳过武器触发器，须在 Play 模式检查真实接触事件。

## 检查命中

工作台的“独立命中测试”会使用私有物理场景，2D 目标的默认位置为 `(3, 1, 0)`。它会列出命中次数和子弹停止原因。射击示例应命中一次；近战的目标可放在 `(1, 1, 0)`。

菜单 **技能编辑器（独立版）→ 2D → 运行适配回归检查** 可重跑集成检查，报告写入工程 `Logs/Skill2DVerification.txt`。先退出 Play 并停止动画预览。

扇形的边缘使用约 3° 的折线补测，飞行扇形按分段采样。高速细小子弹建议用投射物轨道或圆形 / 矩形扫掠。2D 物理忽略 Z，不能用 Z 把同一物理场景的战斗区域隔开。

本次在 Unity **2021.3.8f1** 上验证；没有升级项目版本，Unity 6 尚未实测。依然需要工程已有的 Odin 依赖。

# SkillEditorKit 独立技能编辑器

已加入可切换的 **2D 横版模式**。先读 [2D 使用说明](2D使用说明.md)，可直接打开 `Samples/TwoD/Skill2DDemo.unity` 试射击与近战。

本包是从原工程抽出的独立版本，仅依赖 Unity 和 Odin Inspector & Serializer。它不是原工程的整套迁移包，也不会覆盖原工程的技能类。

## 安装

1. 先备份目标项目，并安装你已有授权的 Odin Inspector & Serializer。不要重复导入两套 Odin。
2. 导入 `SkillEditorKit_2D.unitypackage`（已在本工程直接更新，无需重复导入）。
3. 等待 Unity 编译完成，打开 **技能编辑器（独立版）→ 打开工作台**。
4. 本工程将模块安装在 `Assets/_Project/Modules/SkillEditorKit`，界面资源、示例创建和导出路径均已同步到此位置。跨项目导入此版本时保留该路径与内部结构；如再次移动，需同步修改 Editor 代码中的资源路径。

验证基线为 Unity 2021.3.8f1。未验证其他 Unity 版本、IL2CPP 或移动平台。IL2CPP 等 AOT 平台还需要按目标项目的实际数据重新生成 Odin AOT 支持。

编辑器核心不需要 JKFrame、Addressables、UGUI、Cinemachine、TMP、指定的项目层名称或启动场景。2D 演示脚本使用 Unity Input 读取按键；只启用新 Input System 的项目需改写示例输入或选择 Both。包内不包含 `ProjectSettings`、编译宏、碰撞矩阵或游戏管理器。

注意：原工程的 Odin 目录里存在专为旧日志类型生成的 AOT 文件和扫描配置。跨项目请使用自己的正常 Odin 安装，不要把旧项目生成的 `Sirenix.Serialization.AOTGenerated.dll` 当作通用依赖复制。独立包没有包含 Odin 本体或该文件。

## 五分钟开始使用

- 在工作台点击「新建」，建立自己的 SkillClip。也可以打开 `Samples/Melee.asset` 或 `Samples/Projectile.asset`。
- 展开「预览设置」，点击「使用示例角色」，或者拖入自己的角色预制体。普通预览无需切换场景。
- 支持动画、自定义事件、音效、特效、攻击范围、投射物六类轨道；支持拖动、裁剪、多选、复制、撤销、自动保存和配置检查。
- 点击「命中测试」检查范围、阵营、重复命中、穿透和墙壁阻挡。两个示例在默认测试参数下都预期命中一次。
- 示例角色由 Unity 基本形状组成，不含原游戏的人物模型、商业美术或游戏脚本。需要更好的动作表现时，使用自己的 Animator、动画和材质。

结束帧是最后一个有效帧编号：0～N 共 N+1 个采样点，时间边界为 N ÷ 帧率。例如 30 FPS、结束帧 29，技能结束于约 0.967 秒。投射物可以按配置在技能结束后继续飞行。

## 包内职责

| 部分 | 负责什么 |
| --- | --- |
| Runtime | Odin 技能数据、技能时序、攻击形状、命中规则、投射物和小型接入接口 |
| Editor | 时间轴、属性编辑、检查、预览与隔离命中测试 |
| Samples | Unity 原生基础角色、通用动画、近战及投射物示例 |

类型使用 `SkillEditorKit` 命名空间；编辑器使用 `SkillEditorKit.Editor`。独立程序集为 `SkillEditorKit.Runtime`、`SkillEditorKit.Editor`。和原工程的全局 `SkillClip`、`Skill_Player` 是不同的类型，GUID、菜单和最近使用记录也相互隔离。

原游戏的背包、UI、Buff、技能消耗、冷却、状态机和资源系统不在包中。它们由目标项目通过接口和事件接入，详见 `接入说明.md`。

## 已有技能数据

不要删除旧脚本，也不要把新脚本改成旧 GUID 强行替换旧资产。

如需转换本次原工程的旧 SkillClip，可在原工程的副本中同时导入独立包，然后选中旧技能，使用 **技能编辑器（独立版）→ 将选中的旧版技能另存为独立版**。该操作创建新文件，不修改旧技能；无法识别的事件扩展或字段会中止转换。

动画、音效、特效、ObjectArg 等 Unity 资源保持引用，不会自动复制或改造。包含旧游戏脚本的预制体仍然可能有外部依赖，迁移时应换成纯表现资源或目标项目的预制体。自定义事件中的 AddBuff 等旧标识只作为数据转发，目标项目需要自行解释。

## 命中测试的范围

独立测试使用私有物理场景和同一个运行内核，不调用正式角色的血量、Buff、UI 或资源扣除。伤害是基础攻击乘以技能倍率，不等于完整战斗结算。

武器触发器事件、原生约束驱动的发射挂点会提示跳过或不支持，需要进入目标项目的 Play Mode 验证。单次测试有目标、帧数、片段和运行时间上限；“执行完成”不等于完整战斗验收。

## 验证与限制

交付目录中的验证报告记录实际运行结果，包括编辑器交互、运行模式接入、旧数据转换、Windows 构建及空白项目导入。

原工程专用 Humanoid 模型/走跑动画未随包分发，其对应的旧美术测试没有作为本独立包的验收结果；通用动画融合、挂点、时间轴和命中测试仍然执行。布局采用原生控件尺寸与交互检查，未做实机截图目视验收。

# 开发热更新

## 目标与非目标

后续 P3 在安全点更换玩法逻辑并保留固定结构状态；本轮不实现 Reload 入口或控制器。

## 不变量

活动 continuation、结算事务或已有更新返回 Busy。切换前失败保留原实例；
发布构建关闭更新，不能把 export_state/import_state 的可调用性等同于更新已经实现。

## 线程与所有权

逻辑线程独占旧实例、候选实例和切换屏障；跨线程只传递自有数据。

## 接口与值语义

沿用规划七个入口，快照包含版本、Tick、输入去重及玩法状态。
正式更新命令和候选交付格式在 P3 激活前冻结。

## 失败、取消与退出

候选使用受限能力验证和试运行；成功后重新建立候选并导入原快照。
切换后故障中止本局，不承诺撤销已提交副作用。

## 验证与依赖

依赖 SRV-003～005；P3 建立连续更新、Busy、旧完成包和状态连续性测试后激活。

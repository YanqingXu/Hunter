# 持久化结算

## 目标与非目标

后续 P4 将结果、去重键和累计存档变更提交到同一 SQLite 事务。本轮没有数据库或保存成功接口。

## 不变量

Accepted 不等于 Committed；同 ID 同内容返回已保存结果，不同内容返回冲突。
未完成局不发奖、不隐式恢复；奖励由脚本计算。

## 线程与所有权

单一存档线程独占连接，任务和完成包拥有数据；VM 句柄不进入存档线程。

## 接口与值语义

稳定对局 ID、结果与版本在正式持久化 schema 落地时冻结；完成事件携带操作关联信息。

## 失败、取消与退出

损坏存档保留原文件并报告；退出收敛已接受事务，不依赖最后退出回调保证存档。

## 验证与依赖

依赖调度和桥接。P4 验证重复提交、内容冲突、写入失败及提交前后强杀后激活。

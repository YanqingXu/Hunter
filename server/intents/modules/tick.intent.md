# Tick 与逻辑线程调度

## 目标与非目标

建立单线程 Asio 调度和固定步长脚本驱动；不在原生端复制世界状态。

## 不变量、线程与所有权

单独逻辑线程创建、访问并销毁脚本和网络对象。输入先排队，再在 Tick 边界按序执行。
默认 60 Hz，每次最多补算 4 Tick；超额墙钟积压舍弃并记诊断。快照默认 20 Hz。
单 Tick 最多处理 64 条输入；一次定时回调共享 4 ms 输入工作预算，入口不可中途抢占，
用完预算后保留其余输入 FIFO，推进当前 Tick，并让出事件循环。剩余补算步数丢弃墙钟积压。
入口仍有独立 50 ms 截止预算；一次回调最多越过工作预算一个输入入口和一次 Tick 入口，
不承诺操作系统调度下的硬实时上限。昂贵合法输入不能令一次 Tick 排空整个接收队列。
暂停不推进 Tick，恢复重设下次截止点，不追赶暂停时间。
跨线程命令先检查容量再入队，最多保留一个 Asio 唤醒回调。

## 接口与值语义

Runtime 接收拥有字符串的 JSON 控制命令，输出拥有字符串的控制事件。
TickClock 接收单调时间，返回本次允许推进次数与是否丢弃积压；测试可注入时间。
每次 Script 入口输出独立提交；失败时丢弃该次输出并中止会话。
Tick 限为正 i64 范围，输入序号支持完整 uint64；两者在桥接 JSON 中使用十进制字符串。

## 失败、取消与退出

无认证连接时不推进模拟；认证后的菜单和终态仍处理登录、开局命令。
暂停清空未执行命令和脚本持续/边沿动作，并通知作废输入序号高水位；暂停中新命令明确拒绝。
Resume 等待新输入，不回放动作、不补算暂停时间；输入序号高水位不回退。
初始化失败进入 Faulted；脚本失败、断连终止会话并拒绝继续执行。
Stop 拒绝新命令、取消定时器和网络，释放脚本后进入 Stopped。

## 验证入口与依赖

`hunter_core_contract` 覆盖注入时间下暂停、补算及容量；`hunter_process_integration`
验证真实输入和快照连续性，以及昂贵合法输入积压期间 Pause 可响应且 Resume 不重放旧输入。
桥接生命周期依赖 SRV-004 与 SRV-005。

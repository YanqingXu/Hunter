## 配置不变量、线程与所有权

Lua 负责配置解析、玩法和经济数值，C++ 独占所有跨 Tick 状态及有界原子提交。
普通 Attack、玩家 Skill 和怪物能力分开定义。缺失数值必须填写；未完成记录保持草稿，
不补零、不解析中文描述执行、不将独立测试数值自动写成生产内容。全部根表导出原字段；
Lua 按 `Server` 外键投影当前地图与规则，使用同一实现进行构建和运行时校验。
首批玩家技能为 1/2/4/5/7/8/9/10/11/12/13；3 与零奔跑体耗冲突，不进入生产。
6/14/15 等待对应噪声、箱子及携带规则，不冒充已实现。初始备弹只在初始化发放。
Skill 的对象、机制/数值类别和常驻/一次性/复活后移除生命周期独立表达。

外键和声明参数，只有 `Enabled=1` 且机制已实现的技能进入运行候选。未实现工具和怪物
同样使用各表 `Enabled`；有效配置、默认配装和奖励池不能依赖禁用内容。

## 战斗与复活

Boss 未警戒静止，警戒读巡逻速度、狂暴读警戒速度。血量严格低于阈值才触发，
同 Tick 多次跨越合并一次并记录所有阈值，狂暴中跨新阈值刷新时长，回血不重置标记。
致死优先于狂暴。狂暴取消尚未释放的普通动作，绕过冷却启动指定触发技但保留前摇。
技能按优先级和稳定 ID 选择；非当前组冷却继续推进。已有攻击不会倒带。
召唤技能同一时刻最多一个活召唤物；玩家同时在本体和召唤物圈外才累计消失时间，
回到任一圈清零。召唤物死亡/消失后启动冷却，本体死亡清理召唤物，召唤物不掉奖励。

玩家致死先判断复活资格，存在资格进入等待选择；只有无资格或主动放弃才最终死亡。
等待期间不允许移动/战斗/拾取/撤离，世界继续运行。复活请求携带死亡序号，重复去重。
成功复活才消费技能并清理死亡类型技能。复活生命和体力由必填配置给出，重振旗鼓覆盖
生命为上限。复活后 180 Tick 抑制新目标获取，不等于无敌；旧攻击继续正常判定。
原地空间不足拒绝复活并保持等待，不隐式传送。一次性技能本局消费后不能重新拾取。

## 地图循环

撤离开局可用，可用性与地图标注分离。首次赏金拾取原子提交物品归属、第二波、
警戒倍率和出口标注，失败无部分修改。第二波仅普通/精英，第一波存活怪继续保留。
警戒倍率对存活和新增怪只应用一次。内容验证计算两波、召唤和尸体最大容量。
出生模板、波次、召唤来源和实例 ID 分离。终局冻结后拒绝迟到拾取。
区域随机 Boss 和每区 1～2 个线索由服务端随机状态驱动；每线索排除一个非 Boss 区域。
特殊视角禁止角色移动、攻击、工具和普通交互，世界不停，受伤退出；镜头仅客户端控制。
交互支持即时和读条，后者被其他动作打断；炸药桶子弹延迟/爆炸立即引爆且只结算一次。
`Drop/DropEntry` 定义击杀掉落，`ItemSpawn/SpawnPoolEntry` 定义地图物品刷新概率与权重池。
技能道具用 `Item.SkillIdx` 关联启用技能，开局刷新和局内拾取沿用原生身份与数量边界。

## 弹药、工具与穿透

`ammo_supply` 按当前已装备弹种分组；每种总持有量包含弹匣和备弹，上限为同种已装备
枪械的弹匣容量加有效备弹上限之和。每次只应用一次 `Ammunition.RefillCount`，补量按
稳定枪槽顺序加入备弹，不超过总量上限；全部弹种无可补量时拒绝并保持箱子未使用。
`supply` 优先随机选择一个未满的常规工具，增加其 `Tool.RefillCount`，不超过有效上限。
仅当常规工具全部满且消耗品槽有空位时，按 `Tool.SupplyWeight` 抽一个消耗品。
读条开始仅预检，完成时重新检查并提交；数量、实例与场景使用状态由原生批量接口
原子更新，重放不会重复补给。
`Ammunition.Prop` 为允许穿透的 cover 场景 ID 列表，还须满足场景 `Penetrable=1` 和
剩余 `Penetration`。穿指定掩体消耗次数并按 `Weaken` 削减伤害；`PropDamage` 用于
可受击场景对象。穿怪沿用既有伤害判定，不再占用掩体次数。

## 永久资产

账号、永久猎人、模板和局内实体身份分离。SQLite V2 增量迁移保留旧 UID/局号/历史结果。
招募、配装、技能交易和退役使用持久操作 ID、请求指纹和账号 revision；出战猎人禁止
局外修改。价格/经验和奖励由 Lua 提供，存储层只验证范围和事务前提。
每升一级获得 1 技能点。技能获得记录保存实际支付，移除按支付一半向下取整，支付1返1，
免费和拾取支付0。局内拾取立即可用但只在撤离后持久保留，同技能本局只获得一次。
出战先登记基线和装备占用。撤离原子提交奖励/成长/装备/技能，最终死亡或主动放弃
删除猎人和携带资产，满级退役返仓装备并增加账号经验。普通免费模板作为起步入口。
断线不等同放弃。异常退出只恢复本次未完成出战，不回滚整个账号；重启先检查已提交
结果，已提交死亡/撤离即使回包丢失也不回退。战斗崩溃续玩不在范围。

当前协议6、内容6、Host契约9、上下文/内部状态8、SQLite2；此前内容5/Host契约8属于
历史基线。新补给批量接口升级 Host 契约但不新增跨 Tick 状态。契约变化不得复用版本。

旧版本/错误摘要拒绝，失败候选不得替换活动状态。源码/Bundle双运行时均须测试。
重点覆盖阈值多跨越与同帧死亡、复活迟到请求、初始备弹重复、召唤生命周期、波次原子性、
线索去重、V1迁移、技能退款、终局提交前后强杀与回包丢失。Unity/Android另行验收。

## 失败与恢复

缺少正式数值时关闭对应内容，机制由独立夹具验证。候选导入、赏金拾取、出战及永久交易
失败均保持原状态；异常退出仅恢复未完成出战的持有基线，已提交结果不回退。

# 验证 DEMO 玩法增量

## 目标与非目标

在既有 Windows 单人撤离存档上接通免费局外配装、两种角色、姿态与恢复、三枪三弹、
匕首／急救包／生命针剂／炸药、梯子／补给／可穿掩体。Unity 和 Android 独立验收。
不实现招募、永久死亡、成长天赋、经济、特殊弹药、随机地图或热更新。

## 不变量、线程与所有权

C++ World 独占全部可变状态，Lua 只持句柄与局部计算。逻辑线程和 Tick 边界不变。
免费配装、补给和消费品槽与永久奖励背包分开，绝不写入结算 items。SQLite V1 不迁移。
角色、武器、工具和场景数值来自根源表及显式来源清单；旧首版仅作为回归夹具。
地图2、旧普通怪／Boss攻击时序、掉落2800001／2800002和固定出口保持语义。
新怪物配置使用1002／1003，Boss Rank=3，出口继续绑定出生14。

## 接口与版本

协议v5、内容v4、Host及状态v7；旧协议与内部状态拒绝，旧SQLite档案继续可读。
SRV-012 的 v6 实施记录保留；当前配置来源与职责边界由 SRV-013 升级。
StartReq增加Loadout，缺省为角色1、血段[50,50,25,25]、枪[1,3]、默认弹[1,3]、
工具[30001,30002]、消费品[30004,30006]。先完整校验，再分配持久MatchId。
同请求改变配装返回冲突。槽位一基：武器1至2，常规工具1至4、消费品5至8。
FrameInput增加move_y、run、prone，保持已有单调输入序号和身份校验。
ActionReq增加action_seq、slot、target_id及切枪／选工具／近战／使用／交互。
动作序号连接内单调，缓存最多128条响应；淘汰不降低处理水位，旧序号不重新执行。
暂停作废已排队动作并通知动作水位；恢复不重放。
低频脚本事件5为v7、req_id、kind、slot、target_id、action_seq；身份仍用十进制字符串。
成功输出action包含v5、req_id、world_id、match_id、action_seq，业务拒绝输出error。

## 玩法规则

- 两角色HP150、站立600×1600毫米，走100／跑150／跳240毫米每Tick，负重3。
  匍匐1000×600毫米、速度50；保持脚底，起身检查空间，匍匐跳先起身。
  瞄准仅局部前上象限，移动确定朝向，非法分量裁剪，零向量使用前向。
- 血段由25／50组成且合150，从0累计段界。无伤300Tick后每秒回5，仅到当前段上限；
  恰好在段界不跨段，死亡不回血。治疗可跨段。正伤害重置延迟及整数恢复余量。
- 体力100，停止奔跑／成功跳跃／近战后延迟120Tick，每秒回20。跑跳不耗体力，
  跑步阻止恢复，体力至少1可跑；仅近战耗20，近战冷却30Tick，匕首不耗使用次数。
- 两枪槽、四常规工具槽、四消费品槽，同种工具最多一槽，总枪重不超过3。
  每枪弹匣、备用及冷却独立。切枪取消未完成装填，保留已装弹并清旧开火。
  装填时禁止射击；非当前枪冷却继续。步枪／手枪逐发、霰弹空仓整装否则逐发，每轮180Tick。
- 射程18000／6000／12000毫米。霰弹5射线为-5、-2.5、0、2.5、5度，一发只扣一弹。
  穿怪次数1／0／1，穿过一怪后可伤下一怪；Boss阻断。每穿怪或允许的掩体后
  伤害减50／10／30，掩体不扣穿怪次数。每颗同对象只命中一次，零伤停止。
- 匕首100伤害／600范围；急救包3次、50治疗／120Tick；生命针1次、150治疗／90Tick；
  炸药1次、125伤害／1200半径／180Tick，飞行100毫米每Tick，最多1600毫米。
  前摇移速保留70%，禁止射击近战；切换、成功跳跃、受伤、入梯取消，完成才扣次数。
  常规工具零次留槽，消费品零次清槽。炸药撞击／到射程只爆炸一次，仅伤怪且受实心遮挡。
- 梯子仅接受移动并屏蔽重力，拾取及交互等禁用动作不延后执行；朝端点移动且站立空间足够
  时自动离梯，受阻继续梯上。补给箱每局一次：各常规工具未满则补1，
  再均匀随机补1个可容纳消费品；无可补内容拒绝且不消耗箱子。

## 调度、失败和退出

每Tick：动作门禁取消、移动、玩家战斗及已有飞行物、存活怪物攻击、受伤死亡取消使用、
有效工具完成、自然恢复、掉落与撤离。完成Tick受伤取消且不扣次数，死亡优先。
暂停冻结所有玩法计时；恢复使用整数余量。死亡／放弃／撤离／重开清除使用、装填、输入和飞行物。
场景最多32、飞行物最多16；使用前预留飞行容量。失败不扣资源、不消耗随机数或箱子。
输出及身份约束沿原契约，脚本故障中止会话，不以成功掩盖不完整状态。

## 验证与完成条件

配置严格校验所选记录和引用、未选草稿不影响摘要；新内容与旧地图怪物掉落闭包语义对照。
行为验证覆盖体型／瞄准／血段边界／恢复、装填切枪、散弹穿透、前摇同Tick中断、梯子／补给、
炸药扫掠与容量、动作重放及暂停作废、免费物资不入库、旧档案与崩溃事务回归。
开发与Bundle Runtime全套通过、同Runtime十局、十次启停和解包联调通过后，才标记完成。
